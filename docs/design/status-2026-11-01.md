## Decisions waiting on Franco

- **tundra-tools access in CI.** `gh secret set TUNDRA_TOOLS_TOKEN --repo Hyodar/tundra`
  (a fine-grained token, read-only Contents on `Hyodar/tundra-tools`), or make that
  repository public. Until then no CI job builds an `Image` file.
- **tundra-tools' `go.mod`** says `go 1.25.0` and has no `toolchain` line, so every image
  builds `tdxs` with go1.25.0, without that release's later patches. A
  `toolchain go1.25.N` line in tundra-tools moves it; tundravm needs no change.
- **raiko's ref.** `RAIKO_SOURCE` in `src/tundravm/components/_taiko.py` names
  `feat/tdx`, which `NethermindEth/raiko` no longer has; `feat/tdx-new` and `feat/tdx-old`
  exist. Until one is chosen, `tundravm lock examples/surge-tdx-prover/image.py` fails.
- **`QemuDeployAdapter`** (`src/tundravm/deploy/qemu.py`) is reachable from no command
  (`run` owns QEMU) and kept only by `tests/lifecycle/test_deploy_adapters.py`: delete it,
  or say what it is for.
- **A TDX host** for gate 2, and a GCP project for one real `deploy gcp`, which is also
  the first time the GCE glue units run.
